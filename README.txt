# LivePic v0.5 Mesh Alpha

## 修正内容

- ズーム機能を作り直し
- ホイールズーム対応
- ドラッグ移動対応
- ポイントクリック判定をズーム/移動に対応
- ポイントを大きく表示
- 簡易メッシュ変形を追加
- 顔向きスライダー追加
- A/Dキーで顔向きテスト
- 顔向き自動テスト追加

## 使い方

1. index.html を開く
2. サンプルキャラが表示される
3. ズームしてポイントを打つ
4. 右側の「メッシュ変形」で顔向きを動かす
5. OBS表示を押す

## OBS用

GitHub Pages公開後、URL末尾に `?obs=1` を付けるとOBS専用表示になります。

例:

https://ユーザー名.github.io/LivePic-update/?obs=1

## 注意

これはまだIRIAM風の入口です。
本格的には、顔・目・口・髪ごとの専用メッシュ範囲を分ける必要があります。
