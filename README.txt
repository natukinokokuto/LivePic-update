# LivePic v2.5 Pseudo Live2D Parts

## 今回の方向

ローカル動作前提で、1枚絵を疑似Live2D化する方向へ進めた版です。
まだ本物のLive2Dではありませんが、v2.4より「部位ごとに動いている感じ」を狙っています。

## 追加したもの

- 部位別ウェイト
- 疑似パーツ分離
- 母音口パクの入口
- う口すぼめ
- 奥目圧縮
- 目線残り
- 髪/首/顔の追従率を分離
- 口メッシュの横開き/丸口を追加
- 目メッシュの遅延感を追加

## 確認順

1. サンプル表示
2. 強変形プリセット
3. 顔向き自動 ON
4. 口パクテスト
5. 瞬きテスト
6. 部位別ウェイト / 疑似パーツ分離をON/OFF比較

## メモ

今後さらにIRIAMに寄せるなら、
次は「パーツ範囲を手描きマスクで指定」「前髪/顔/目/口の個別レイヤー化」に進むのが本命です。
