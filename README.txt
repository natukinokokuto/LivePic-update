# LivePic v0.9 Face Tracking Boost

## 今回の変更

- 顔トラッキング入力のメーターを追加
  - 顔向き
  - 口開き
  - まばたき
- 顔向き増幅を追加
- 反応速度を追加
- 慣性/ぬるさを追加
- カメラ表情ON時の反映を強化
- 口パク/瞬きの反応を強めに調整
- 顔あり/顔なしステータス表示を追加

## 使い方

1. GitHub Pagesにアップ
2. 画像を読み込む
3. 「画像から顔認識して自動配置」
4. 「カメラ表情 ON」
5. メーターが動くか確認
6. 右側の「顔向き増幅」「口感度」「まばたき感度」「反応速度」「慣性」を調整

## 注意

MediaPipeをCDNから読み込むため、ネット接続とHTTPS環境が必要です。
GitHub Pagesで試すのが一番安定します。
