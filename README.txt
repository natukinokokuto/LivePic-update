# LivePic v2.0 Real Mesh Engine Alpha

## 重要

これは今までの「黒い口を上に描く」方式を捨てた版です。
画像そのものを三角メッシュに分割し、頂点を動かして変形します。

## 入れたもの

- Canvas2D三角メッシュ変形エンジン
- 顔向きで頭部/頬/髪/首を頂点変形
- 口開きで口周辺と顎を頂点変形
- 瞬きで目周辺を頂点変形
- 顔認識ポイント配置
- 顔トラッキング
- マイク口パク
- 自動まばたき
- IRIAM寄せプリセット
- OBS表示

## 使い方

1. GitHub Pagesにアップ
2. 画像を読み込む
3. 「画像顔認識」または固定プリセット
4. 「IRIAM寄せプリセット」
5. 「顔向き自動 ON」でまず変形確認
6. 「口パクテスト」「瞬きテスト」でメッシュ変形確認
7. カメラを使うなら「顔トラッキング ON」

## 正直な限界

これはIRIAM完全再現ではありません。
でも今回から、見た目の本質は「貼り付け」ではなく「画像そのものの変形」に変わっています。
