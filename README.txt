# LivePic v2.2 Mesh Debug Power

## 今回の修正

v2.1で「変形しない」状態になったため、描画基盤から作り直しました。

主な原因候補だった Canvas の DPR / setTransform 周りを避け、
Canvas座標をCSSピクセル基準に統一しています。

## 入れたもの

- 三角メッシュ変形を強制的に見える強変形プリセット
- メッシュ線表示ON/OFF
- 顔向き自動の振れ幅強化
- 口パクテストの変形強化
- 瞬きテストの変形強化
- グローバル変形倍率
- 顔/口/目のガイド範囲表示
- v2.1の頬/鼻筋/口/瞬き補正を維持
- OBS表示維持

## まず確認する順番

1. サンプル表示
2. 強変形プリセット
3. 顔向き自動 ON
4. 口パクテスト
5. 瞬きテスト

ここでメッシュ線と画像が動けば成功です。
