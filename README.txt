# LivePic v3.1 Live2D Bone Rig

## 今回の方向

「もっとLive2Dしてほしい」に合わせて、
メッシュ変形よりも「骨・親子パーツ・表情プリセット」寄りへ大きく寄せました。

## 追加/修正

- ボーン制御モード
- 頭ボーン
- 首ボーン
- 体ボーン
- 髪ボーン
- 表情: 笑顔
- 表情: 通常
- 口角上げ
- 口閉じ吸着
- 口横幅ボーン
- 笑顔目
- 上まぶた
- 下まぶた
- 口/目を子パーツとして動かす処理を強化
- メッシュ変形は補助に弱める
- 顔向きで崩壊しにくい設定へ調整
- サンプル用リグ設定を再調整

## 使い方

1. サンプル
2. サンプル用リグ設定
3. 自動マスク作成
4. 補助表示を全部OFF
5. 表情: 笑顔 / 通常
6. 口パクテスト / 瞬きテスト
7. 顔向き自動 ON

## メモ

まだ本物のLive2Dのような手作業パーツ分けではありません。
でもv3.1からは「1枚布を歪ませる」より「パーツを骨に追従させる」方向を優先しています。
