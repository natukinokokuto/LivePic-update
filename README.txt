# LivePic v0.8 Face Detect + Tracking Alpha

## 今回の修正

- 「ポイント自動配置」を本物の顔認識寄りに変更
- MediaPipe FaceMeshで画像から顔ランドマーク検出
- 左目/右目/口/あご/首/体/髪中心を自動配置
- カメラ表情トラッキング追加
- カメラから口開き・まばたき・顔向きを取得
- 手動のまばたき/口パクテストを強化
- 口パク量/まばたき量の初期値を強めに調整

## 重要

顔認識とカメラ表情トラッキングはMediaPipeをCDNから読み込みます。
そのため、GitHub PagesなどのHTTPS環境での使用推奨です。

ローカルの file:// でも画面表示はできますが、ブラウザや環境によって顔認識/カメラが動かない場合があります。

## 使い方

1. GitHub Pagesにアップ
2. 画像を読み込む
3. 「画像から顔認識して自動配置」を押す
4. 必要ならズームしてポイント修正
5. 「カメラ表情 ON」で表情トラッキング
6. 「OBS表示」で配信用表示

## OBS

GitHub Pages公開後、URL末尾に `?obs=1`

例:
https://ユーザー名.github.io/LivePic-update/?obs=1
