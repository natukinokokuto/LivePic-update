# LivePic v2.4 Display Guarantee

## 修正内容

v2.3でも「キャラが読み込めない/表示されない」状態があるため、
表示保証の構造に変更しました。

## 重要変更

- 起動時はローカル保存データを自動復元せず、必ずサンプルを表示
- 通常画像を先に描画してからメッシュを重ねる
- メッシュ描画でエラーが出たら通常画像に自動フォールバック
- Image / Mesh / Render の状態表示を追加
- メッシュ濃さスライダー追加
- 通常画像を下に表示 ON/OFF 追加

## 確認順

1. 開いた瞬間にサンプルが出るか
2. Image: OK になっているか
3. Mesh: OK になっているか
4. 強変形プリセット
5. 顔向き自動 ON
6. 口パクテスト / 瞬きテスト

この版でサンプルすら出ない場合は、GitHub Pagesのキャッシュ、アップロード先、または古い app.js を読んでいる可能性が高いです。
