# LivePic v2.9 Contour Masks Big Rework

## 今回の大工事

楕円だけの雑な切り抜きから一歩進めて、
口・目の周辺画像を読んで輪郭っぽい部分を拾う処理を入れました。

## 追加したもの

- 輪郭検出マスク
- 口輪郭感度
- 目輪郭感度
- 輪郭拡張
- 輪郭なめらか
- 肌色補完サンプル範囲
- 口輪郭だけ再検出
- 目輪郭だけ再検出
- 失敗時は楕円マスクへフォールバック
- 穴埋め時の周囲色サンプリング改善

## 仕組み

ローカルのCanvas処理だけで、

- 明暗差
- 色差
- エッジ
- 周囲の肌色/背景色
- ポイント周辺の範囲

を見て、口や目の輪郭らしい場所をマスク化します。

## 使い方

1. 画像読み込み
2. 顔認識 or 固定プリセット
3. 自動マスク作成
4. マスク表示ONで口/目の範囲を見る
5. 口輪郭感度・目輪郭感度・輪郭拡張・輪郭なめらかを調整
6. 口輪郭だけ再検出 / 目輪郭だけ再検出
7. 補助表示を全部OFF
8. 動作確認

## 注意

これはまだ完全自動ではありません。
次の本命は「ブラシでマスクを手直しする機能」です。
