# 立ち絵モーションLite Prototype v0.1

1枚絵を読み込んで、目・口・首などの位置を指定し、疑似モーションを付ける試作アプリです。

## 使い方

1. `index.html` をブラウザで開く
2. 画像を読み込む
3. 左の「顔中心」「左目」「右目」「口」「首」「体中心」を選ぶ
4. プレビュー上をクリックして位置を指定
5. 右側のスライダーで動きを調整

## 操作

- A / D : 顔傾き
- W / S : 上下移動
- Space : 口パク
- B : まばたき

## 現在できること

- 1枚絵読み込み
- 目/口/顔/首/体中心の指定
- 呼吸っぽい上下揺れ
- 左右ゆらぎ
- 顔傾き
- 簡易口パク
- 簡易まばたき
- OBS風フルスクリーン表示
- 設定JSONの書き出し/読み込み

## 次に入れると強い機能

- Webカメラの顔トラッキング
- 口開閉の自動連動
- まばたき自動連動
- 透過OBS専用ページ
- メッシュ変形による顔向き表現
- 髪/胸/肩の揺れ範囲指定
