# LivePic Working Alpha v0.4

1枚絵を読み込んで、まばたき・口パク・ゆらぎを付ける試作アプリです。

## v0.4 修正

- プレビューのズーム機能追加
- マウスホイールで拡大/縮小
- ドラッグで表示位置を移動
- ポイントを大きく表示
- 選択中ポイントをリングと十字線で強調
- ポイント大/小切り替え
- OBS表示ではズーム/パンの影響を受けないように調整

## 使い方

1. `index.html` をブラウザで開く
2. 最初はサンプルキャラが表示されます
3. 自分の画像を使う場合は画像を読み込みます
4. ズームして顔まわりを大きく表示
5. 「顔中心」「左目」「右目」「口」「首」「体中心」をクリック配置
6. 「マイク口パク ON」を押す
7. OBS表示を押す

## GitHub Pages

このZIPの中身をリポジトリ直下に置けばOKです。

```
index.html
style.css
app.js
README.txt
```

OBS用URLは末尾に `?obs=1` を付けます。

```
https://ユーザー名.github.io/LivePic-update/?obs=1
```
