# LivePic v2.6 Live2D-like Layers

## 今回の方向

前回のスクショで「1枚布を強く回すと崩壊する」と分かったので、
IRIAM寄りから一度戻して、Live2Dっぽい「パーツが重なって動く」方向に寄せました。

## v2.6の変更

- 顔全体を強く潰す変形を抑制
- 疑似Live2Dレイヤー追加
  - 顔レイヤー
  - 首レイヤー
  - 髪レイヤー
- ベース画像を常に表示して崩壊を防止
- 頭の小さな回転・移動を追加
- 髪と首は遅れてついてくる
- メッシュ変形は弱めにして補助役へ変更
- 顔向き自動の振れ幅を抑制
- Live2D寄せプリセットに変更
- メッシュ線は初期OFF

## 確認順

1. サンプルまたは画像読み込み
2. Live2D寄せプリセット
3. 顔向き自動 ON
4. 口パクテスト
5. 瞬きテスト
6. レイヤー重ね量 / 変形を控えめにする を調整

## メモ

今後はこの方向で、次に「手動マスクで前髪/顔/目/口の範囲を指定」できるようにすると一気にLive2D寄りになります。
