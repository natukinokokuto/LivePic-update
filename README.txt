# LivePic v2.3 Image Load Fix

## 修正内容

v2.2で「キャラが読み込めない」問題が出たため、画像読み込みまわりを優先修正しました。

- サンプルキャラをSVGデータURLではなくCanvas生成PNGに変更
- 画像読み込み中/成功/失敗ステータスを表示
- FileReader失敗時の表示追加
- 保存復元に失敗してもサンプルを自動表示する保険を追加
- v2.2の強変形メッシュエンジンは維持

## 確認順

1. 開いた直後にサンプルキャラが出るか
2. 出ない場合は「サンプル」ボタン
3. 画像選択で「画像読み込みOK」が出るか
4. 強変形プリセット
5. 顔向き自動 ON
6. 口パクテスト / 瞬きテスト

## メモ

まず画像が出ないと何も検証できないので、この版は表示安定を最優先にしています。
