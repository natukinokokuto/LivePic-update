# LivePic v0.7 IRIAM Direction Alpha

## 今回入れたもの

- ブロックメッシュをやめて、滑らかストリップ変形へ変更
- 顔向きで頬・顔面がなめらかにズレる方向へ調整
- メッシュ密度スライダー
- 顔向き自動テスト
- マイク音量に応じた口パク
- 口の横幅/開き調整
- まばたきの補間
- ランダム二重まばたき
- 目線ゆらぎ
- ズーム/ドラッグ編集
- OBS表示

## 使い方

1. `index.html` を開く
2. サンプルキャラが出る
3. 右側の「顔向き自動テスト ON」で変形確認
4. マイクONで口パク確認
5. ズームしてポイントを調整

## OBS

GitHub Pages公開後、URL末尾に `?obs=1`

例:
https://ユーザー名.github.io/LivePic-update/?obs=1

## 正直な限界

まだIRIAMには遠いです。
ただし、v0.6までの「ブロックが動く」段階から、
v0.7では「顔を滑らかに歪ませる」方向へ寄せています。

次に必要なのは「目・口・頬・髪の専用変形範囲マスク」です。
