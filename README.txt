LivePIC Semantic Engine v5

既存LivePICのCUT/IRIAM系処理を完全に使わない、意味付きメッシュ方式の確認用ビューアです。

v1からの変更:
- 画面構成を作り直し、表示キャンバスを最優先で常時表示
- 画像を読み込んだ瞬間に必ず中央プレビュー
- .cmo3読込結果をログとレイヤーカードに表示
- ドラッグ&ドロップ対応
- ホイール拡大縮小、ドラッグ移動
- 瞬き/口パク/振り向き/揺れテスト
- CUTマスク、円形補完、自動切り抜きは一切なし

注意:
現時点の.cmo3はArrayBufferで実読み込みし、ファイル名から意味スロットへ登録します。
Cubism内部メッシュ解析はまだ未実装です。
