# LivePic v3.3 Local Segmentation Parts

## 今回の目的

巨大楕円マスク問題への対応として、
ブラウザ内ローカル処理で「肌・髪・目・口・服」を色分類する簡易セグメンテーションを追加しました。

## 追加機能

- 色分類セグメント生成
- 分類表示ON/OFF
- 分類からパーツ生成
- 分類PNG保存
- 肌検出幅
- 髪検出幅
- 口赤検出
- 分類なめらか
- semantic parts:
  - skin/face
  - hair
  - eye
  - mouth
  - cloth/body

## 使い方

1. サンプルまたは画像読み込み
2. 顔認識 or 固定プリセット
3. 色分類セグメント生成
4. 分類表示で確認
5. 分類からパーツ生成
6. パーツ確認
7. 生成パーツでリグ適用

## 注意

これはクラウドAIではなく、ローカルの色分類です。
本格的なAIセグメンテーションほど高精度ではありませんが、巨大楕円よりは部位認識に寄せています。
