# LivePic v2.7 Auto Cut + Inpaint Layers

## 今回の方向

Live2D化に必要な「切り抜き」「穴埋め」「レイヤー重ね」の入口を入れました。
クラウドAIではなく、ブラウザ内ローカル処理です。

## 追加機能

- 自動マスク作成
  - 顔
  - 髪
  - 左目
  - 右目
  - 口
  - 首
- 疑似切り抜きレイヤー生成
- 元画像の穴埋め
  - 周囲色サンプリング
  - 簡易ぼかし
- マスク表示ON/OFF
- レイヤー再生成
- 自動切り抜きレイヤーモード
- 穴埋め背景ON/OFF
- マスク境界ぼかし
- 穴埋め強さ

## 使い方

1. 画像読み込み
2. 顔認識 or 固定プリセット
3. 自動マスク作成
4. Live2D寄せプリセット
5. 顔向き自動 ON
6. 口パク/瞬きテスト

## 注意

これは完全自動Live2Dではありません。
現段階では、顔/髪/目/口の範囲を楕円マスクで推定する半自動方式です。

次にやるなら、マスクをブラシで手直しする機能が本命です。
