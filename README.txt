# LivePic v2.1 IRIAM Refined Mesh

## 今回の方向

v2.0で見えた「三角メッシュで画像そのものを変形する」方向を、
もっとIRIAMっぽく細かく寄せた版です。

## v2.1で入れた改善

- メッシュ密度の初期値アップ
- 三角の継ぎ目を軽減する微小拡張描画
- 顔向き時の頬の立体感
- 鼻筋シフト
- 顎の追従を強化
- 口メッシュを上唇/下唇/顎で分けて変形
- 瞬きメッシュを目周辺だけ潰す方向へ調整
- 髪と首の遅れを弱めすぎず自然寄りに調整
- IRIAM寄せプリセット更新

## 使い方

1. GitHub Pagesにアップ
2. 画像を読み込む
3. 「画像顔認識」または「固定プリセット」
4. 「IRIAM寄せプリセット」
5. まず「顔向き自動 ON」で動きを確認
6. 「口パクテスト」「瞬きテスト」で変形確認
7. カメラを使うなら「顔トラッキング ON」

## メモ

まだ本物のIRIAMではないですが、v2.0よりも「顔・口・目が絵そのものとして動く」方向へ寄せています。
