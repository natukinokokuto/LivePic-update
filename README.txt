# LivePic Working Alpha v0.3

1枚絵を読み込んで、まばたき・口パク・ゆらぎを付ける試作アプリです。

## v0.3 修正

- 最初からサンプルキャラが表示されるように修正
- 「サンプルキャラを表示」ボタン追加
- 保存データがない場合でも真っ白/空表示にならないように修正
- 画像読み込み後に自動でポイント配置されるように再確認
- GitHub Pages直置き構成を維持

## 使い方

1. `index.html` をブラウザで開く
2. 最初はサンプルキャラが表示されます
3. 自分の画像を使う場合は画像を読み込みます
4. 必要なら「顔中心」「左目」「右目」「口」「首」「体中心」をクリック配置
5. 「マイク口パク ON」を押す
6. OBS表示を押す

## GitHub Pages

このZIPの中身をリポジトリ直下に置けばOKです。

```
index.html
style.css
app.js
README.txt
```

GitHub Pagesで公開後、OBSブラウザソースには以下のように `?obs=1` を付けるとOBS専用表示になります。

```
https://ユーザー名.github.io/LivePic-update/?obs=1
```

## 注意

マイク機能はブラウザの仕様上、GitHub PagesなどのHTTPS環境か、localhostで動かすのが安定です。
ローカルの `file://` でも表示は動きますが、環境によってマイク許可が出ない場合があります。
