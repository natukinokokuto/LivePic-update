# LivePic v3.0 Sample Character + Rig Fix

## 今回の修正

「その黒髪キャラをサンプルにしてほしい」と「口も目も動かない」問題への対応版です。

## 追加/修正

- 黒髪キャラのサンプル画像を同梱
- サンプルボタンで sample_character.png を読み込み
- 読み込み失敗時は旧Canvas生成サンプルにフォールバック
- サンプル用リグ設定ボタン追加
- 動作テスト強ボタン追加
- 口レイヤー開きスライダー追加
- 口レイヤー上下スライダー追加
- 目レイヤー閉じスライダー追加
- 目レイヤー追従スライダー追加
- 口レイヤーを上下移動＋拡縮で開閉しやすく修正
- 目レイヤーを縦スケールで閉じるよう修正
- 口/目輪郭検出の範囲を少し拡大

## 使い方

1. サンプル
2. サンプル用リグ設定
3. 自動マスク作成
4. 補助表示を全部OFF
5. 動作テスト強
6. 口パクテスト / 瞬きテスト

## 注意

同梱サンプルはテスト用の生成サンプル画像です。
本番の絵師さんの絵を使う場合は、ローカルで読み込んで検証してください。
