# LivePic v1.0 IRIAM Full Experiment

## 今回の目的

v0.9までの「画像がふわふわするだけ」から脱出して、
IRIAMっぽさに必要な誤魔化しをまとめて入れた実験版です。

## 入れたもの

- 体固定
- 頭部疑似レイヤー
- 顔だけ楕円マスクで再描画
- 横向き時の隙間カバー
- 顔向きで頭だけ動く
- 首が遅れてついてくる
- 髪が遅れて逆方向に揺れる
- 呼吸を全体上下ではなく胸の微拡大に変更
- 口パクを強く見えるように変更
- まばたきを強く見えるように変更
- 顔トラッキング対応
- 顔認識ポイント配置
- IRIAM寄せプリセット
- OBS表示

## 使い方

1. GitHub Pagesに上げる
2. 画像を読み込む
3. 「顔認識ポイント配置」
4. 「IRIAM寄せプリセット」
5. 「顔トラッキング ON」
6. 必要ならポイントを手動調整
7. OBS表示

## 重要な限界

これはまだ本物のIRIAMではありません。
1枚絵だけでやっているため、完全な目・口・髪の裏側生成はできません。

ただし今回から、
「画像全体を揺らす」方式ではなく、
「体固定＋頭部疑似レイヤー＋表情誇張」方式に寄せています。
